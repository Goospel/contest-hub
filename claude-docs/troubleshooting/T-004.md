# T-004 · AI Gateway 인증은 됐는데 추론만 403 (카드 미등록)

- **증상**: `vercel link` 로 받은 `VERCEL_OIDC_TOKEN` 으로 `gateway.getAvailableModels()` 는 **성공**했다 — 306개 모델이 정상적으로 돌아왔고 `gateway.tools` 에 `exaSearch`·`parallelSearch`·`perplexitySearch` 도 보였다. 그런데 같은 토큰으로 `generateText` 를 호출하니 403 이 떨어졌다.
  ```
  statusCode: 403
  {"error":{"message":"AI Gateway requires a valid credit card on file to service requests...",
   "type":"customer_verification_required"}}
  ```
- **원인**: AI Gateway는 **인증(OIDC)과 결제 자격(카드 등록)을 따로 검사**한다. 목록 조회 같은 메타 엔드포인트는 인증만 보고 통과시키지만, 실제 토큰을 소비하는 추론 엔드포인트(`/v4/ai/language-model`)는 카드 등록을 요구한다. **무료 크레딧조차 카드를 등록해야 풀린다.** 목록 조회가 되는 것을 보고 "인증은 됐으니 코드 문제겠지"라고 오진하기 딱 좋다.
- **해결**: Vercel 대시보드에서 팀에 결제 수단을 등록한다 (`https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fai%3Fmodal%3Dadd-credit-card`). 카드 등록은 사용자 본인이 해야 하는 일이라 대신 할 수 없다.
- **재발방지**: 게이트웨이 프로브는 **목록 조회로 끝내지 않는다** — 인증 확인은 반드시 토큰을 소비하는 최소 호출까지 해봐야 의미가 있다. 403 을 만나면 `responseBody.error.type` 을 먼저 본다: `customer_verification_required` 는 결제 문제이고 코드·토큰과 무관하다. 부수 확인: 이 403 응답의 요청 바디에 `tools: [{type:'provider', name:'web_search', id:'gateway.perplexity_search'}]` 와 `responseFormat: {type:'json', schema:...}` 가 **함께** 실려 있었다 — 웹검색 도구와 구조화 출력의 조합이 API 수준에서 유효하다는 증거다.
